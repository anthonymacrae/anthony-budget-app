# Macrae Work & Family Calendar redesign

Upload the files in this folder to `work-family-calendar/` in the GitHub repository. Replace `index.html`, `manifest.json`, and `service-worker.js`; add `macrae-banner.jpg`. Keep this separate from root budget-app files.

The update adds the Macrae tartan/crest banner, vibrant styling, month/week/day controls, same-day overlap warnings, a next unscheduled-date indicator, and quick family entry. Earnings, actual pay, CSV import and local backup code are preserved. Data remains in browser storage on the device. Google Calendar and budget-app sync are not connected.
